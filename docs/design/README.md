# PaperMirror HTML 交互演示

这是一个独立、零依赖的完整产品交互原型，不连接 Zotero，也不会发起真实翻译请求。配置、术语表、笔记和阅读偏好保存在浏览器本地。

直接双击 `index.html`，或在本目录运行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

可体验：

- 原文、PDF 覆盖翻译、左右对照三种阅读模式
- 拖动分栏、交换左右、显示/隐藏原文、同步滚动
- 选句深度讲解、逐段选择、复制译文和阅读笔记
- 完整设置中心与服务商预设、连接测试
- 术语表编辑、导出和本地保存
- 缓存、隐私和仅本地模式演示
- 阅读字号、深浅主题及设置持久化

这是交互和视觉验收版本。翻译与连接测试使用模拟数据，不会传输 API Key 或论文内容。
