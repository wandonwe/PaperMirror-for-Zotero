# PaperMirror for Zotero 2.0.6 全面审核报告

- 审核对象: 版本 2.0.6(提交 ccb2d68),696→704 项测试全绿
- 审核方式: 五个维度并行审查(缓存/并发、隐私安全不变量、近五批修复回归、UI/生命周期、传输层/引擎),关键发现经人工在源码逐一复核(标【已复核】)
- 上一轮: 审核报告-2.0.0.md 的 P0/P1/P2/P3 已在 2.0.1–2.0.6 五批全部处理

## 1. 一句话结论

五批修复的主体是扎实的 —— 上一轮的专项复查(写队列自删、fnv1a64、scheduler 双职责、runSeq 止损、raceSignal listener、样式注入配对等十余项)**均未发现回归**。但本轮发现 1 个新 P1(会话打开/销毁竞态泄漏)、一族「配置变更/清缓存与 in-flight 写盘」的时序缺陷,以及 4 处「修复声称覆盖、默认路径实际未覆盖」的修不彻底。共 P1×1、P2×15、P3×约 20。

## 5. 已验证成立的不变量(未发现破坏)

- **模型输出只经 textContent 渲染**: 全仓 grep innerHTML/outerHTML/insertAdjacentHTML/document.write/createContextualFragment/eval/new Function —— 代码命中 **0**(5 个命中全是注释)。唯一 DOMParser 是构建期 inline 的品牌 SVG 常量且校验 nodeName==='svg'。译文渲染路径(fillStyled/overlay/pane)逐一核实只用 createTextNode/createElement + textContent,标签名闭集 'b'|'i'。
- **无遥测**: 全仓 https:// 枚举,出站主机只有翻译服务端点与文档链接注释;pdfService 强制 loopback;字体加载是扩展内资源。
- **缓存不含密钥**: cacheSchema/cacheManager grep apiKey 0 命中;settingsIdentityHash 六成分不含 apiKey。
- **密钥不进日志**(插件侧): 密钥入内存仅 credentialStore 两条路,读取/写入首行 registerSecret,先于任何日志;logger 全部出口过 sanitize;copyDiagnostics 仅计数与原因码枚举。桥接脚本例外见 P2-8。
- **原文/译文不进日志**: 全部含 text/translat 字样的 logger 调用(约 40 处)核实只有页号/块 id/计数/毫秒;语料导出三重自我声明。桥接例外见 P3。
- **五批修复的专项复查全部通过**: 写队列 tail 自删身份守卫、sweep 时效闸、fnv1a64、scheduler active 双职责、cancelAndWait→ensurePage 无重复入队窗口、runSeq 并发去重、孤儿错误闸、renderTask cancel 路径、raceSignal listener 清理、样式注入双路径、2.0.3 owner 门闸、exportTranslatedPdf 随机名实现 —— 均无回归。

## 6. 建议修复顺序

1. **第一批(数据完整性 + P1)**: P1-1(open/destroy 竞态)、P2-1(writeSegments 截断)、P2-2(compress 覆写)、P2-3(刷新全部竞态)、P2-7(删除密钥清 fallback)—— 全是数据丢失/泄露级,改动小、可测。
2. **第二批(修不彻底收尾)**: P2-5(参考文献墨迹默认失效)、P2-6(轮换取舍)、P2-9(胶囊串扰)、P2-12(bingFree 错误分类)。
3. **第三批(状态正确性 + 传输)**: P2-4(设置 quiesce)、P2-10/11(compress 唤醒/预取页记账)、P2-13/14/15。
4. **P3 按需**: 几何审计重算、flashKeptIndicator 兜底、占位符 PM2.5、fail-closed、桥接隐私三项优先。
