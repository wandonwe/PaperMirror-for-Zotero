# 4.2.0 发布验证（2026-09-23）

## 通用规则审核

本轮生产代码未加入论文名称、固定页码或文献专属单元格文字匹配。标题合并依据相对字号、上下位置和横向交叠；说明型表格依据表题与重复标签/描述结构；缩写续表依据键值对齐。识别器仍有适用范围：英文表题与拉丁缩写，不宣称适用所有语言和版式。

新增回归变更页码为42、替换表题编号和标签文字，并做0.8/1.25倍缩放和平移；两种表格结构均保持独立。真实 ESC 坐标夹具使用生产 textContentItemRect 转换，包含旋转文字。旧代码复现11块错误结构，新代码保留16块；旧近似夹具不能复现，本版已替换。
