## 范围

- 粗体小节标题：提取时从内嵌字体名取字重，短的整行粗体单独成标题（断段证据 `weight-change`，在列表判定之前分类）。
- 表格单元格语境：每个单元格随请求附上所在列、行的标题；扫描仪 / 设备 / 软件型号名原样保留并接受原样返回；提示词规则 `tableCells` v5。
