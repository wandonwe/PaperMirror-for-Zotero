## 运行前

1. 保持 Mac 已解锁、Zotero 位于前台。主 A/B 有 54 页，每个版本两轮、每轮四相位，耗时较长；运行期间不要锁屏、切换文献、调整窗口/侧栏宽度、缩放或滚动阅读器。
2. 关闭 Zotero 已打开的 PDF 阅读标签。脚本会检查没有现存阅读器，并用互斥锁阻止两个审核脚本同时启动。不要在前一脚本仍运行时再次点击 Run。
3. 确认候选包来自当前代码，且以下本地文件齐全。任一缺失时脚本在修改安装状态之前报错：
   - `dist/zotero-bilingual-reader-4.10.0.xpi`
   - `output/public-4.9.0.xpi`（已保存的公开正式包）
   - `output/audit-runtime.js`
   - `output/symbols/source-audit-4.9.js` 与 `source-audit-candidate.js`
   - `output/random-audit-plan.json`
   - `scripts/zotero/ink-clip-check.js`
4. 两个源文取证 bundle 是独立、只读的同版本提取器，不访问安装插件的私有会话。候选 bundle 生成后只改了 `strictPageReplacement` 的显示宽度处理，提取代码未变；若之后再改任何提取代码，必须重建候选取证 bundle，不能继续使用旧 bundle。

## 第一步：最终候选与公开 4.9.0 A/B

在 Zotero 菜单选择 **Tools → Developer → Run JavaScript**，勾选 **Run as async function**。把 `REPO` 替换成当前工作副本的绝对路径，执行：

```javascript
return eval(await Zotero.File.getContentsAsync('REPO/output/run-final-local-ab.js'));
```

脚本按顺序安装公开 4.9.0、候选 4.10.0，每次等 4 秒并检查插件版本、启用状态和 `Zotero.PaperMirror.version`。每个版本先对 Bae 第 2、9、19、21 页做只读源文取证，再对下面 54 页测量两轮：

| 文献 | PDF 页码（从 1 开始） | 页数 |
| --- | --- | ---: |
| Kitagawa 2021 | 1–13 | 13 |
| Gori | 1–10 | 10 |
| Siemens DCE-CT | 1–10 | 10 |
| Bae 2010 | 1–9、18–24 | 16 |
| Mets 2013 | 1–5 | 5 |

每轮相位为 `[0, 0.25, 0.5, 0.75]`。输出为：

- `output/final-local-ab-status.json`：进度、两版两轮汇总、逐块比较、重复一致性和恢复状态。

公开 4.9.0 是带已知问题的对照：它的裁切读数应完整记录，不要求对照自身 `auditPass=true`。候选两轮必须被裁块为 0，且没有跳过、噪声、未稳定页或错误。结构未变页面逐块检查，不得缺页或丢块；结构改变的页面须逐项核对源文、数字、行矩形及保留原文的原因。重复轮次结果若不一致，要查明并复测，不能择优取一轮。

## 无翻译请求与恢复

两个脚本在安装和打开阅读器前将 `localOnlyMode` 设为 true。由于该选项仍允许 localhost 服务，脚本还暂时把 `Zotero.HTTP.request` 替换成只拒绝请求的函数，覆盖当前插件全部服务商共用的 HTTP 层；不记录 URL、请求体或凭据，只累计 `blockedHTTPAttempts`。缓存未命中时保留原文，不生成新译文。运行期间 Zotero 的其他 HTTP 操作也会被暂时拒绝。

正常结束或捕获异常时，脚本都会关闭审核阅读器、恢复公开 4.9.0、原 HTTP 函数及运行前的 localOnlyMode。以状态文件中的 `finished`、`restoredVersion: "4.9.0"`、`httpRestored: true`、`localOnlyRestored: true` 和错误列表核验；不要把没有 `finished` 的中间文件当作完成结果。

如果强制退出、应用崩溃或恢复报错，先重启 Zotero，确保旧脚本已经终止，再在 Run JavaScript（async）执行：

```javascript
return eval(await Zotero.File.getContentsAsync('REPO/output/restore-public-4.9.0.js'));
```

恢复脚本读取 `output/audit-recovery.json`，重装公开 4.9.0 并恢复运行前偏好，结果写入 `output/recovery-status.json`。不要在主审核仍运行时执行恢复脚本。

`numericAuditPass` 只是自动计数检查，不能替代源文守恒、结构变化解释及原文/译文并排目视审核。两个待运行入口目前只做了语法检查；共享 runtime 的 5 项离线 mock 检查通过，覆盖 HTTP 阻断、正常恢复、候选安装失败、缺文件、状态写入失败和重复启动。这些离线检查不属于 Zotero 实机验收。
