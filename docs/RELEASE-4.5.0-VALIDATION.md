# 4.5.0 发布验证

2026-10-27。以 4.2.2 为上一个正式版，整合 4.2.3pre1–pre5 的原文自动解析、覆盖模式解析宿主、整段双击、点击外部关闭、说明型表格及小数保护修复；发布前追加 PDF 文档内的 Esc 关闭和左侧省略零小数保护。

## 行为与阶段职责

- 选择阶段：只读取原文文本层，拖动结束且选区稳定后请求；手动段落解析抑制同次单词选区请求。设置关闭、旧选区变化、关闭会话与关闭卡片均清理对应请求或监听。
- 会话阶段：解析请求用身份及取消信号防止过期结果回写；覆盖与对照各有宿主，同一卡片切换宿主，不强制切换阅读模式。
- 结构阶段：两列表格在散文合并前固定行列归属；表题、双表头、多行标签、条目内容与脚注分离。多列表格反例和同页独立网格保留原处理路径。
- 数值阶段：小数和公式保护保持完整性，包含 ≈33.6、≈31.08、.75≤1 与 .5≈.75；不对引擎自身的全部数字准确性作保证。
- 显示阶段：保留完整文本、原文区域、图片避让及几何审计；无法放置时仍可查看完整译文。

## 本地验证

- 代码类型检查与测试类型检查通过。
- `npm test`：1507 项测试通过，零失败、零跳过；41 页既有布局快照、源文字符清单和请求计划基线未改动。
- `node scripts/check-release-layout.mjs`：解析卡片真实 DOM 与 iframe 交互、两列说明表、单列说明表、缩写表、推荐表及短段落边界均通过。两列说明表按 0.8、1.2、2 倍显示验证完整文字及非重叠。
- 解析测试包含实际跨文档 Esc/外部点击、复制与保存、宿主切换、关闭后的监听清理，以及模拟服务延迟返回时不重新打开卡片。测试不调用模型接口。
- 真实 PDF 第 4 页的原始文字位置用于验证十组标签与说明、表头和脚注对应；更换文字、页码、平移、缩放、打乱输入与六列表格反例均有回归。
- 正式 XPI、版本清单及自动更新地址由发布流程校验，下载时以 GitHub Release 资产为准。

## 范围与升级

聚焦发布检查通过不等于历史完整视觉套件全绿；密集页面已有的容量与字形边界限制仍存在。不通过截断文字、跨格扩展或降低验收阈值隐藏这些限制。本次未在 Zotero 实际阅读界面执行完整人工验收，浏览器验证不能替代真机。

升级后对先前出现错位或数值异常的页面点击“刷新”重新翻译，避免沿用旧译文；无需清空整个库的缓存。原文结构缓存使用新的结构版本，译文缓存仍按源内容与设置识别。
