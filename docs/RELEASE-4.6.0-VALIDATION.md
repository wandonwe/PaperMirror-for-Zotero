## 升级和缓存边界

4.5 用户通过现有 Zotero 更新通道升级，作者元数据随插件更新。没有全库缓存自动删除或全篇强制重译。

普通“刷新本页”跳过页面缓存，但继续复用合格的段落缓存，适合重新提取结构及补齐显示。旧译文若存在统计值错误，应对受影响的译文段落右键选择“重译此段”，明确重新请求该段；这与复用合格段落的普通刷新不同。

## 验证的实际限制

- 本地函数测试、浏览器回放和生成 PDF 检查不等同于 Zotero 实际阅读界面验收。
- 浏览器使用的文字测量与 PDF 字体排版属于两条输出路径，不能据其中一项通过宣称逐像素一致。
- 密集版式中，完整译文可能仍无法放入可靠边界；保留原文及原因优于裁切或覆盖相邻内容，完整译文入口继续可用。
- 数值保护保证识别到的原始统计片段不会被占位符拆开，不代表可自动修正所有上游 OCR、提取或服务商翻译错误。
- 目录与文件权限收紧为尽力实现的平台能力；不支持 POSIX 权限的平台遵循其原有访问控制。
