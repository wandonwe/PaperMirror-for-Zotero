# PaperMirror 4.7.0 发布验证记录

日期：2026-10-30。Author：`wangdongwei`。本版从 4.6.0 后的内容完整性、视觉对齐、跨栏跨页续句及图例修复整理，不新增产品功能。

**本地候选三已通过 Kitagawa 目标图例原生验收、完整测试和安装包校验。** 公开版本与资产以 [GitHub v4.7.0 页面](https://github.com/wandonwe/PaperMirror-for-Zotero/releases/tag/v4.7.0)为准；正式发布后的资产身份须另行独立核对，本记录不提前声明已经公开发布。

- 完整单元与集成测试 **1910/1910 项通过**，零失败；图例分项在此前 1847 项基础上增加 38 项，再在 1885 项基础上增加 25 项遮罩几何、BFS 标记墨迹保护、JSON/结构缓存保真及页面身份回归。测试类型检查与源码类型检查通过，最终候选三构建、打包和 XPI 校验通过。
- 41 页布局跨度语料、源文字符清单、IR 与请求计划纳入回归。最后一轮图例改动未改变这 41 页既有基线；不据此声称 4.6.0 以来每份快照均未发生经审阅的变化。

## 既有浏览器门槛与其他限制

最终冻结源码的完整浏览器入口仍因 Bell 第 11 页、缩放 1 的一条参考文献回退与历史期望不同而停止，不能称为完整入口通过。18 组同输入对照（4.6.0 与本版各 18 次渲染）证实失败集合完全一致：额外条目在两版均有约 0.499 px 字形越界，因此整段保留原文；870 个原文黑墨像素没有被遮罩覆盖。定向发布界面、表格和控制对齐检查通过。

真实译文矩阵另行完成了 7 份样例、3 个缩放，共 21 个场景；有六项 **P1 最低成功落版数量门槛**（`minimumCommitted`）失败。它比较实际提交的块数，不是最小字号限制。以下为本次实际结果，取代此前保存的四项历史计数：

同环境、同一输入下又对正式 4.6.0 与最终源码执行全部 21 对场景，共 42 次渲染；提交数量、回退 ID、原因和除计时外的统计一致。没有新增数量失败、新增回退或提交减少；11 个完整回退父块的 2441 个原墨迹像素采样均未被遮罩覆盖。这些属于两版共有的可用性限制，仍保留失败记录，没有降低门槛；定向图例通过不能覆盖这些限制。

其他限制：

- 联合源句翻译的定向验收覆盖大模型路径；免费 Google/Bing 和 DeepL 保留逐块契约，未据此认证其跨页语义。
- 图例识别要求至少三行重复短标记；两项图例、光栅标记、长条形色块及证据有歧义的情况保留既有路径。
- 跨页源句只取得有界的相邻物理页证据。数字和受保护字面量仍按片段严格校验，某些合法语序变化可能被拒绝并保留原文；不以整句数字清单相同代替局部对应检查。
- 共享句的单段重译复用同一完整句结果以保持两端一致，不独立重新生成半句。普通刷新继续复用合格段落缓存，不等于强制重新生成全部内容。
- 密集版式、非目标术语、其他图注及既有未恢复块仍可能存在。本版没有整篇语义认证，也没有全部引擎、所有缩放、操作系统或所有 PDF 的视觉保证。
- 严格网页排版、Zotero 原生显示和生成 PDF 是独立输出路径；其中一项通过不能自动认证其他路径。

## 升级、配置与发布身份

保留原有阅读模式、解析设置、模型池、密钥与更新通道，不要求全局清除翻译缓存。新版源文分组和源句证据改变对应缓存身份，旧的合并图例或上下文缺失结果不能冒充新分组。其他旧页面若仍有问题，可先刷新受影响页；某些数值错误仍需对受影响段落明确重译。

正式版本应统一为 `4.7.0`，Author 为 `wangdongwei`，插件 ID 保持 `zotero-bilingual-reader@local`。发布流程需核对 `v4.7.0`、`zotero-bilingual-reader-4.7.0.xpi` 及其 `updates.json` 指向同一正式结果。正式包、已安装包、公开资产和原生验收结果应分别记录，不用旧验收包哈希或浏览器结果替代。
