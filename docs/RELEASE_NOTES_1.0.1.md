# PaperMirror 文镜 1.0.1

PaperMirror 是一款面向 Zotero 阅读场景的论文翻译插件。它可以直接在 PDF 阅读器中
提供覆盖原文翻译或左右对照翻译，并尽量保留论文原有的页面、段落、图片和表格结构。

本版重点提升长文档的连续阅读体验：当前阅读页面始终优先处理，切页后旧任务不会再
回头覆盖当前页面；文字读取较慢时会自动使用页面上已经显示的文字继续翻译，无需手动
刷新。表格文字现在按单元格翻译，数字、单位和统计值保持原位，以减少缺译、重叠和
结构错乱。

插件支持多家翻译服务、性能模式、术语表、翻译缓存、刷新本页、重新翻译、同步滚动
与缩放，以及统一的任务进度和错误提示。扫描版或没有文字层的 PDF 仍需要先进行 OCR；
结构特别复杂的页面效果也会受到原文件质量影响。
