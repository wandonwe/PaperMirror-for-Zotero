# 真实 PDF 发布验收

自动测试不能复现 Zotero PDF.js 的字体、缩放、延迟渲染和复杂页面。每次正式发布前，
必须在 Zotero 中用合法自备文献完成以下检查；测试文件不提交仓库。

## 固定样本集

至少各一份：单栏论文、双栏论文、三栏论文、长指南、文字型表格、数值型表格、
多图/多图注页面、公式密集页面、参考文献页面，以及无文字层扫描件。

## 必测动作

1. 打开覆盖翻译与左右对照翻译，确认两侧页码、缩放比例和页面尺寸一致。
2. 连续快速滚动 10 页再返回当前页；当前页应先完成，旧页译文不得闪现或覆盖。
3. 在 75%、100%、150%、200% 间缩放；已完成译文不得消失，图片不得被遮挡。
4. 等待一页完成后收起/展开胶囊并刷新本页；不应产生重复通知或重复覆盖层。
5. 检查表格：表格线、斑马纹、行列位置不变；文字格有完整译文；数字、单位、
   置信区间和 P 值保持原样；不得把正文写入表格。
6. 检查长段落、跨栏段落、标题和图注：不缺句、不跨栏、不续页、不盖图；无法安全
   放入原框时保留原文，而不是溢出到其他区域。
7. 对扫描件确认显示“需要 OCR”，而不是永久加载或空白页面。

## 发布门槛

- `npm test` 全绿。
- `npm run package` 成功且自动通过 XPI 内容校验。
- 上述样本没有 P0（遮图、跨栏叠字、页面消失、任务卡死）问题。
- P1 问题必须修复或写入发布说明；验收人记录 Zotero 版本、操作系统和样本类型。
